# MW.AI media

Place production cinematic assets in this directory:

- `mw-ai-intro.mp4` — muted, loopable hero video
- `mw-ai-poster.jpg` — poster/fallback frame
- `mw-ai-wireframe.svg` — optional wireframe overlay

The app falls back to the generated Canvas scene when the video is not present, so the site remains functional before assets are uploaded.
